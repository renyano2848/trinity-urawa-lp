Solution

私たちが解決できる課題

姿勢・動作パターン・神経筋機能に着目した多角的アプローチで、
サッカー選手一人ひとりの課題に本気で取り組みます。

Solution 01
スプリント・加速力の強化

神経系の反応速度と股関節・足部の爆発的収縮力を改善し、0〜10mの初速と最高速度を同時に向上させます。

Solution 02
キックパフォーマンスの最大化

体幹回旋力・股関節屈曲力・足首の固定力の連動性を強化し、キックの威力・精度・疲労耐性を向上させます。

Solution 03
怪我予防・再発防止プログラム

膝・股関節・足首の動作パターン歪みを特定し根本から修正。繰り返す怪我のサイクルを断ち切ります。

Solution 04
方向転換・アジリティ × 認知トレーニング

切り返しの速さは「筋力」だけでなく、視覚認知・固有感覚・反応速度に大きく依存します。認知系トレーニングと感覚統合を組み込むことで、判断からアクションまでの時間を短縮し、サイドステップや方向転換のキレが飛躍的に向上します。

Solution 05
毎日の継続サポート

毎日の継続をするために、必要なエクササイズの共有やトレーニングプログラムの作成を行い、自宅でも実践できる環境を整えます。

Cognitive Training

認知系トレーニングで
判断力・反応速度を鍛える

サッカーのパフォーマンスは「筋力」だけでは決まりません。
相手の動きを読み、瞬時に判断し、身体を動かす──
この認知×運動の連動こそが競技力の核心です。

  • 視覚認知トレーニング リアクションボールや視覚刺激を使い、動体視力と空間認識を強化。周囲の状況判断スピードが上がります。
  • 反応速度の向上 ランダムな刺激への素早い反応を繰り返すことで、神経系の伝達速度が高まり、初動の速さが変わります。
  • デュアルタスクトレーニング 身体動作と認知課題を同時に行うことで、試合中に考えながら動く能力を効率よく習得できます。
  • 固有感覚の統合 不安定環境下での運動制御を高め、ドリブル・ターン・シュートの精度と安定性を向上させます。

Program

トレーニングプログラム

さまざまな目標とシーズンサイクルに合わせた3フェーズプログラムを提供しています

Phase 01 · 1〜4週
動作リセット期

機能障害の特定と神経筋パターンの再教育。まず身体の「使い方」を根本から整えます。

  • 姿勢・動作アセスメント
  • 過緊張筋のリリース
  • 弱化筋の活性化
  • 体幹ニュートラル習得
  • 固有感覚再教育
Phase 02 · 5〜12週
筋力・出力強化期

サッカーに直結する動作で使える筋力を構築。競技パフォーマンスに直結する出力を高めます。

  • 片脚スクワット・RDL系
  • 股関節爆発的収縮
  • 体幹回旋力強化
  • ハムストリングス強化
  • プライオメトリクス導入
Phase 03 · 13週〜
スポーツ動作統合期

構築した筋力・感覚をサッカー動作に完全統合。競技パフォーマンスを最大化します。

  • スプリントメカニクス最適化
  • 方向転換ドリル
  • キックバイオメカニクス
  • 試合前後コンディショニング
  • シーズン管理プロトコル
